## 1. 우리가 만든 것

혈당 예측 모델 2종:

| | 모델 1: 식사 기반 | 모델 2: 시계열 기반 |
|---|---|---|
| **언제 쓰나** | 음식을 먹었을 때 | 현재 혈당 측정치가 있을 때 |
| **입력** | 탄수화물 양, 식사 시각, 현재 혈당, 체중, 공복혈당, 활동량, 당뇨 유형 | 최근 60분간의 혈당 측정값 (5분 간격 × 12개) |
| **출력** | 식후 5분~120분 혈당 예측 (5분 단위, 24개 시점) | 현재부터 120분 후까지 예측 (5분 단위, 24개 시점) |
| **최종 선택 구조** | LSTM (장단기 기억 신경망) | NowLSTM |

두 모델은 상호 보완적입니다. 식사 데이터가 있으면 모델 1, 없으면 모델 2를 씁니다.

## 2. 사용한 데이터

### 데이터 종류

| 구분 | 설명 | 규모 | 특징 |
|------|------|------|------|
| **시뮬레이터 데이터 (sim_v3)** | 혈당 시뮬레이터로 생성한 가상 환자 데이터 | 35,640명 × 6일 분량 | 양이 많고 다양하지만 현실과 다소 차이 있음 |
| **실제 환자 데이터 (Shanghai)** | 중국 상하이 당뇨 환자 임상 데이터 | 107명 (T1D 6명, T2D 101명) | 현실 반영이나 정상인 데이터 없고 양이 적음 |

### 데이터 전처리 과정

```
원본 데이터
  ↓
① 혈당 측정값 5분 간격 정렬 (빈 구간은 앞 값으로 채움)
  ↓
② 식사 이벤트와 매칭 (식사 시점 기준 ±150초 이내 혈당)
  ↓
③ 탄수화물 양·혈당 등 숫자를 동일한 기준으로 표준화
   (모든 수치를 -3~+3 범위로 변환. 이유: 단위가 다른 여러 수치를 같이 학습하기 위해)
  ↓
④ 환자 단위로 학습/검증/테스트 분리 (70% / 15% / 15%)
   (같은 환자가 학습과 테스트에 동시에 들어가지 않도록)
```

### 학습에 사용된 데이터 양

**모델 1 (식사 기반)**
| 구분 | 건수 | 비고 |
|------|------|------|
| 학습 | 51,239건 | sim_v3 |
| 검증 | 10,947건 | sim_v3 |
| 테스트 | 10,876건 | sim_v3 |

**모델 2 (시계열 기반)**
| 구분 | 건수 | 비고 |
|------|------|------|
| 학습 | 684,085건 | sim_v3 (슬라이딩 윈도우 방식으로 생성) |
| 검증 | 146,622건 | sim_v3 |

> 슬라이딩 윈도우: 연속된 혈당 데이터에서 60분 입력 + 120분 출력 묶음을 30분씩 이동하며 잘라냄

## 3. 학습 방법

### 공통 설정

| 항목 | 값 | 의미 |
|------|-----|------|
| 최대 에폭 | 50 | 전체 학습 데이터를 최대 50번 반복 학습 |
| 배치 크기 | 64 | 한 번에 64건씩 묶어서 학습 |
| 학습률 | 0.001 | 한 번에 얼마나 크게 조정할지 |
| 조기 종료 | 5 에폭 | 검증 성능이 5번 연속 개선 안 되면 학습 중단 |
| 손실 함수 | MSE | 예측값과 실제값의 차이 제곱 평균 최소화 |
| 최적화 | Adam | 학습률 자동 조정 방식 |

조기 종료 덕분에 불필요한 과학습을 방지합니다. 실제로 LSTM은 8~10 에폭에서 종료됐습니다.

### 모델 구조 비교 실험 (E1)

모델 1에서 3가지 구조를 비교했습니다.

| 구조 | 특징 | val RMSE@30min |
|------|------|---------------|
| Ridge (선형 회귀) | 단순, 빠름 | 11.44 mg/dL |
| MLP (다층 신경망) | 비선형 관계 학습 | 10.27 mg/dL |
| **LSTM (장단기 기억)** | 시간 흐름 고려 | **10.21 mg/dL** ← 선택 |

Ridge: 선형 회귀 방식. 입력과 출력의 직선적 관계만 학습.  
MLP: 여러 층의 신경망. 복잡한 비선형 패턴 학습 가능.  
LSTM: 시간 순서를 기억하는 신경망. 식후 혈당 변화의 시간적 흐름에 유리.

## 4. 평가 방법

### 평가 지표

**RMSE (평균 제곱근 오차)**
예측값과 실제 혈당의 평균 오차입니다. 단위는 mg/dL.

```
예) RMSE@30 = 10 mg/dL
    → 30분 후 혈당 예측이 평균 ±10 mg/dL 오차
```

**Clarke 오류 격자 분석 (임상 안전성 평가)**
혈당 오차가 의료적으로 안전한 범위에 있는지 판단합니다.

| 구역 | 의미 |
|------|------|
| A 구역 | 오차 20% 이내 — 임상적으로 안전 |
| B 구역 | 오차 크지만 잘못된 치료 유발 안 함 |
| C~E 구역 | 잘못된 치료로 이어질 수 있는 위험 오차 |

목표: A+B 구역 비율 95% 이상

### 임상 기준

| 기준 | RMSE@30min |
|------|-----------|
| 우수 | 15 mg/dL 이하 |
| 임상급 | 10 mg/dL 이하 |

## 6. 데이터 전략 비교 실험 (E2)

시뮬레이터 데이터와 실제 환자 데이터를 어떻게 조합하는 게 좋은지 실험했습니다.  
**모두 LSTM으로 고정**, 데이터 구성만 다르게 설정.

| 시나리오 | 학습 데이터 | 테스트 데이터 | RMSE@30 | RMSE@60 | RMSE@120 |
|---------|-----------|------------|---------|---------|---------|
| SimOnly | 시뮬레이터 51,239건 | 시뮬레이터 | 10.30 | 11.32 | 11.62 |
| SimEvalReal | 시뮬레이터 51,239건 | 실제 환자 412건 | 39.54 | 62.72 | 71.09 |
| RealOnly | 실제 환자 2,178건 | 실제 환자 412건 | 21.65 | 36.50 | 48.45 |
| Mixed | 시뮬레이터+실제 53,417건 | 실제 환자 412건 | 22.14 | 38.09 | 50.11 |

### 결과 해석

**SimOnly**: 시뮬레이터끼리 테스트하면 성능이 좋음 (RMSE@30 = 10.30). 하지만 이건 같은 종류의 데이터끼리 평가한 것.

**SimEvalReal**: 시뮬레이터로 학습한 모델을 실제 환자에게 적용하면 오차가 39.54로 급격히 나빠짐. 시뮬레이터와 현실의 혈당 패턴 차이가 크기 때문.

**RealOnly**: 실제 환자 데이터 2,178건만으로 학습. 오차 21.65. 데이터가 너무 적어 성능 한계.

**Mixed**: 시뮬레이터와 실제 데이터를 합쳐도 RealOnly보다 오히려 약간 더 나쁨 (22.14). 시뮬레이터 데이터가 96% 비중을 차지하면서 모델이 실제 환자 패턴보다 시뮬레이터 패턴에 편향됨.

### 핵심 결론

> **어떤 전략으로도 실제 환자에게 바로 적용하면 성능이 좋지 않습니다.**  
> 실제 사용자에게 의미있는 예측을 하려면 **개인화(파인튜닝)이 필수**입니다.

## 7. 개인화가 왜 중요한가

혈당 반응은 사람마다 매우 다릅니다.

```
같은 밥 한 공기를 먹어도:
  A씨 (T1D, 60kg): 30분 후 혈당 +80 mg/dL
  B씨 (T2D, 90kg): 30분 후 혈당 +40 mg/dL
  C씨 (정상, 70kg): 30분 후 혈당 +25 mg/dL
```

베이스 모델은 평균적인 패턴을 학습합니다. 개인화는 베이스 모델 위에 특정 사용자의 데이터로 미세 조정(파인튜닝)하는 과정입니다.

```
베이스 모델 (시뮬레이터로 학습된 일반 모델)
  ↓ 파인튜닝 (사용자 본인의 데이터로 미세 조정)
개인화 모델 (해당 사용자 패턴에 최적화)
```

파인튜닝은 모델 가중치만 조정하며, 정규화 기준(scaler)은 베이스 모델 것을 그대로 씁니다.

## 7-1. 개인화 효과 실험 결과

실제 환자 데이터(Shanghai, 85명)로 파인튜닝 효과를 검증했습니다.

### 실험 방법

- 각 환자의 식사 기록을 시간순으로 앞 70% → 파인튜닝, 뒤 30% → 평가
- 파인튜닝 전 오차(base) vs 파인튜닝 후 오차(personalized) 비교

### 결과 요약

| 항목 | 수치 |
|------|------|
| 평가 환자 수 | 85명 |
| 개선된 환자 비율 | 95% (81명) |
| 파인튜닝 전 평균 오차 (RMSE@30) | 39.71 mg/dL |
| 파인튜닝 후 평균 오차 (RMSE@30) | 21.97 mg/dL |
| 평균 개선폭 | 17.73 mg/dL (39% 감소) |

### 주목할 사례

| 환자 | 파인튜닝 전 | 파인튜닝 후 | 비고 |
|------|-----------|-----------|------|
| 2060 | 17.15 | **7.20** | 임상급 달성 |
| 2055 | 47.63 | **10.01** | 임상급 달성 |
| 2017 | 57.75 | **13.03** | 우수 기준 충족 |
| 2073 | 112.60 | 47.50 | 베이스 최악 → 절반 이하로 감소 |

> 파인튜닝 설정: 에폭 30회, 학습률 0.0003, 최근 42건 식사 기록 사용
> 결과 상세: `reports/personalize_test/results.csv`
