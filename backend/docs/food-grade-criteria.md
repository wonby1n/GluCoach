# 음식별 혈당 반응 등급(SABCD) 산출 기준

## 1. 개요

### 1.1 목적
CGM(Continuous Glucose Monitoring) 데이터를 기반으로 사용자가 섭취한 음식이 식후 혈당에 미치는 영향을 정량적으로 평가하고, 직관적인 등급(S/A/B/C/D)으로 제공한다.

### 1.2 평가 지표
식후 혈당 상승 기울기(postprandial glucose rise slope, 단위: mg/dL/min)를 단일 지표로 사용한다. 본 지표는 식후 혈당의 절대값보다 **상승 속도**가 대사 부담과 더 직접적으로 연관된다는 임상적 합의에 기반한다.

### 1.3 적용 방식
본 등급은 사용자의 건강 상태(비당뇨/T1D/T2D)와 무관하게 **모든 사용자에게 동일한 절대 기준**으로 적용된다. 음식 자체의 혈당 부담을 객관적으로 평가하는 것이 목적이므로, 동일 음식은 누가 섭취하더라도 동일한 등급 기준으로 판정된다.

---

## 2. 산출 방식

### 2.1 입력값 정의

| 변수 | 정의 | 단위 |
|---|---|---|
| `baseline` | 식사 시작 시점의 혈당값 | mg/dL |
| `peak` | 식후 측정된 최고 혈당값 | mg/dL |
| `minutes` | `baseline`에서 `peak`까지의 경과 시간 | min |

### 2.2 계산 공식

```
slope = (peak - baseline) / minutes    [mg/dL/min]
```

### 2.3 구현 (Java / BigDecimal)

```java
BigDecimal slope = (peak.getValue().subtract(baseline.getValue()))
    .divide(BigDecimal.valueOf(minutes), 1, RoundingMode.HALF_UP);
```

소수점 첫째 자리까지 반올림(HALF_UP)하여 등급 판정에 사용한다.

---

## 3. 등급 체계

### 3.1 SABCD 컷오프

| 등급 | slope 범위 (mg/dL/min) | 참고 분포상 위치 | 해석 |
|:---:|:---:|:---:|---|
| **S** | `slope ≤ 0.5` | 하위 10% 이하 | 매우 안정적 반응 |
| **A** | `0.5 < slope ≤ 1.0` | 10 ~ 50% | 평균보다 양호한 반응 |
| **B** | `1.0 < slope ≤ 1.4` | 50 ~ 75% | 평균 수준의 반응 |
| **C** | `1.4 < slope ≤ 1.7` | 75 ~ 90% | 가파른 반응 |
| **D** | `slope > 1.7` | 90% 초과 | 정상 분포를 벗어나는 급격한 상승 |

### 3.2 판정 의사코드

```
if    slope ≤ 0.5  → S
elif  slope ≤ 1.0  → A
elif  slope ≤ 1.4  → B
elif  slope ≤ 1.7  → C
else               → D
```

> 경계값은 하한 등급으로 귀속시킨다(예: `slope = 1.0` → A 등급).

## 4. 임계값 산출 근거

### 4.1 참고 문헌

> **Freckmann G, Schauer S, Beltzer A, Waldenmaier D, Buck S, Baumstark A, Jendrike N, Link M, Zschornack E, Haug C, Pleus S.**
> *Continuous Glucose Profiles in Healthy People With Fixed Meal Times and Under Everyday Life Conditions.*
> Journal of Diabetes Science and Technology. 2024 Mar;18(2):407–413.
> DOI: [10.1177/19322968221113341](https://doi.org/10.1177/19322968221113341)
> PMC: [PMC10973852](https://pmc.ncbi.nlm.nih.gov/articles/PMC10973852/)

본 등급의 모든 컷오프는 위 단일 연구에서 직접 도출하여 출처의 일관성을 확보하였다.

### 4.2 연구 설계 요약

| 항목 | 내용 |
|---|---|
| 대상 | 비당뇨 성인 36명 (남 15, 여 21) |
| 평균 연령 | 23.7 ± 5.7세 |
| 평균 BMI | 23.8 ± 3.5 kg/m² |
| 측정 기기 | FreeStyle Libre (Abbott), 참가자당 2개 센서 동시 착용 |
| 측정 기간 | 14일 (식사 시각 고정 4일 + 자유 식사 7일 분석 대상) |
| 분석 식사 수 | 432끼 (참가자 1인당 12끼) |
| 보정 방식 | Passing-Bablok 회귀를 통한 SMBG 기반 재보정 (MARD 6.5%) |

### 4.3 식후 혈당 분포 (Table 2 발췌)

논문 Table 2에서 보고한 비당뇨인의 식후 혈당 변화 사분위 분포는 다음과 같다.

| 통계량 | Premeal Glc (mg/dL) | Time to peak (min) | Peak Glc (mg/dL) | **Glc increase (mg/dL)** |
|---|:---:|:---:|:---:|:---:|
| Mean ± SD | 92.8 ± 9.4 | 50 ± 19 | 143.3 ± 23.5 | 50.9 ± 23.6 |
| 2.5% | 77.0 | 26 | 107.1 | 18.6 |
| **10%** | 81.7 | 32 | 116.0 | **23.4** |
| **25%** | 86.4 | 38 | 127.0 | **32.6** |
| **50%** (중앙값) | 91.7 | 47 | 139.8 | **47.3** |
| **75%** | 98.3 | 56 | 157.4 | **65.2** |
| **90%** | 104.7 | 78 | 174.2 | **80.3** |
| 97.5% | 113.6 | 105 | 198.9 | 113.7 |

### 4.4 임계값 매핑

각 분위의 `Glc increase`를 해당 분위의 `Time to peak`로 나누어 slope으로 환산한 후, 5단계 등급의 경계값을 도출하였다.

| 분위 | Glc increase ÷ Time to peak | 환산 slope | 매핑된 등급 경계 |
|:---:|:---:|:---:|:---:|
| 10% | 23.4 ÷ 32 | ≈ **0.5** | S / A |
| 50% | 47.3 ÷ 47 | ≈ **1.0** | A / B |
| 75% | 65.2 ÷ 56 | ≈ **1.4** | B / C |
| 90% | 80.3 ÷ 78 | ≈ **1.7** | C / D |

### 4.5 컷오프 선정의 근거 논리

본 등급은 절대 기준이지만, 그 절대 기준의 **레퍼런스 분포**로는 정상 대사 기능을 가진 비당뇨인의 식후 혈당 분포를 채택하였다. 이는 "건강한 대사 반응의 일반적 분포"를 음식 평가의 객관적 잣대로 삼기 위함이다.

- **S/A 경계 (0.5)**: 참고 분포의 10% 분위. 이 값 이하는 매우 안정적인 반응으로, 단백질·지방 위주의 식사 또는 저탄수화물 식사에서 주로 관찰된다.
- **A/B 경계 (1.0)**: 참고 분포의 중앙값. 정상 대사 반응의 평균보다 양호한 반응(A)과 평균 수준의 반응(B)을 구분한다.
- **B/C 경계 (1.4)**: 참고 분포의 75% 분위. 이 값을 초과하는 반응은 정상 대사 반응 중에서도 상위 25%에 해당하는 가파른 반응으로, 식이 패턴 점검이 필요하다는 신호로 작용한다.
- **C/D 경계 (1.7)**: 참고 분포의 90% 분위. 이 값을 초과하는 반응은 정상 분포 범위를 거의 벗어나며, 음식 자체의 혈당 부담이 매우 높은 경우에 해당한다.

## 5. 한계 및 고려사항

### 5.1 데이터 한계
- 참고 연구의 표본은 평균 연령 약 24세의 독일인 36명으로, **국내 사용자 및 고령층에 일반화하기에 한계**가 있다. 향후 한국인 대상 CGM 데이터 확보 시 컷오프 재보정이 필요하다.
- 측정 기기는 1세대 FreeStyle Libre이며, 기기별 정확도 차이로 인해 ±10% 수준의 오차가 발생할 수 있다.

### 5.2 개인 간 변동성
- 동일 음식에 대한 식후 혈당 반응은 개인차가 크다는 점이 다수의 연구에서 보고되고 있다(Zeevi et al., 2015 등). 본 등급은 일반 인구 분포 기준이며, 향후 사용자별 baseline 분포에 따른 개인화 등급으로의 확장을 권장한다.

### 5.3 단일 지표 사용의 제약
- 본 기준은 slope 단일 지표만을 사용한다. 동일한 slope이라도 식사 직후 일찍 peak이 발생한 경우와 늦게 peak이 발생한 경우의 임상적 의미는 다를 수 있으며, 향후 보조 지표(2시간 iAUC, peak 절대값 등)의 병기를 검토할 수 있다.

### 5.4 측정 신뢰도
- CGM의 간질액 혈당 측정은 모세혈당과 5~20분의 시간 지연(lag time)이 존재한다.
- baseline 시점은 식사 시작 직전 15분 평균을 사용하는 것이 단일 시점 측정보다 견고하다.

### 5.5 사용자 대사 상태에 따른 등급 분포 차이
본 등급은 모든 사용자에게 동일한 절대 기준으로 적용되므로, 사용자의 대사 상태에 따라 등급 분포에 자연스러운 차이가 발생한다.

- **당뇨인(T1D, T2D) 사용자**: 인슐린 분비 또는 감수성 저하로 인해 동일 음식에 대해서도 비당뇨인 대비 더 가파른 식후 혈당 상승을 보이는 경향이 있다. 이로 인해 동일 식단에서도 B~D 등급의 비중이 높게 나타날 수 있으며, 이는 시스템의 오류가 아니라 음식의 객관적 혈당 부담을 정확히 반영한 결과다.
- **인슐린 저항성·전당뇨 사용자**: 비당뇨인 대비 등급이 한 단계 낮게 나오는 경향이 있을 수 있다.
- **활용 권고**: 절대 등급은 음식 선택의 객관적 지표로 사용하고, 사용자의 개선 추이를 보여주기 위해서는 본인의 과거 평균 slope 대비 상대적 변화를 별도 지표로 병기하는 것이 권장된다.
