## 프로젝트 개요

혈당 AI 에이전트(kiki)의 상태를 YG300 피코 프로젝터로 시각화하는 장치.  
Raspberry Pi Zero 2W가 소켓 서버로 동작하며, 안드로이드 앱/백엔드에서 명령을 받아 영상을 전환한다.

```
[백엔드 / Android 앱]
        │  TCP 소켓 (port 9999)
        ▼
[Raspberry Pi Zero 2W]
        │  HDMI (mini-HDMI → HDMI)
        ▼
[YG300 피코 프로젝터]  →  벽/천장에 투사
```

## 보조배터리 권장 스펙

### 필수 조건

Raspberry Pi Zero 2W 특성상 **저전류 자동 차단(Auto Power-Off)** 되는 제품은 사용 불가.  
Pi Zero 2W 아이들 전류 ≈ 120mA → 대부분의 저가 보조배터리가 이 수준에서 꺼짐.

| 항목 | 요구 스펙 |
|------|-----------|
| 출력 전압 | 5V |
| 출력 전류 | 2A 이상 |
| 용량 | 10,000mAh 이상 (약 10시간 구동) |
| 저전류 유지 | **필수** — "저전류 기기 지원" 또는 "Always-On" 기능 |
| 연결 포트 | USB-A (micro-USB 케이블 연결) |

### 권장 제품 (국내 구매 가능)

| 제품 | 용량 | 특징 | 예상 가격 |
|------|------|------|-----------|
| **샤오미 파워뱅크 3 Pro** (PLM07ZM) | 10,000mAh | 저전류 기기 지원, 얇고 가벼움 | ~25,000원 |
| **Anker PowerCore 10000 Redux** | 10,000mAh | 저전류 안정적, 검증된 제품 | ~30,000원 |
| **INIU BI-B41** | 10,000mAh | 저전류 스마트 충전 지원 | ~20,000원 |
| **Coms IBS082** | 10,000mAh | 국내 제품, 저전류 지원 명시 | ~22,000원 |

> **구매 전 확인 포인트:**  
> 쿠팡/네이버에서 "저전류 기기 충전 가능", "라즈베리파이 사용 가능" 리뷰 확인 필수.  
> 샤오미 10000 Pro 또는 Anker PowerCore 계열이 가장 안정적.

### 참고 — 예상 구동 시간

| 배터리 용량 | Pi Zero 2W (영상 재생 중, ~400mA) |
|-------------|-----------------------------------|
| 5,000mAh | 약 5시간 |
| 10,000mAh | 약 10시간 |
| 20,000mAh | 약 20시간 |

## 3D 프린트 마운트

`powerbank_mount.scad` 파일 참고.

### 설계 목표 (워치형 케이스)

- 보조배터리 + Pi Zero 2W를 워치형 케이스에 일체 수납
- **바텀 케이스** (배터리 슬롯) + **탑 리드** (Pi 수납, 스냅핏 뚜껑) 2피스 구조
- 상하 손목 러그 4개 — 22mm 표준 밴드 장착 가능
- 탑에 투명창 자리 (워치 페이스 스타일)
- 측면 케이블 포트 홀 (micro-USB, HDMI mini, USB-A)
- 서포트 없이 출력 가능

### STL 내보내기 순서 (OpenSCAD)

```
PRINT_PART = 1  → F6 → Export STL  (바텀 케이스)
PRINT_PART = 2  → F6 → Export STL  (탑 리드, 뒤집혀서 나옴)
```

### 출력 설정 권장 (SSAFY 프린터 기준)

| 항목 | 값 |
|------|-----|
| 재료 | PLA |
| 레이어 높이 | 0.2mm |
| 인필 | 25% |
| 서포트 | 불필요 |
| 속도 | 50mm/s |
| 탑 리드 방향 | 뒤집어서 (탑 리드 코드가 자동 처리) |
